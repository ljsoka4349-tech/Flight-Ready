앱 소개

Flight Ready는 실제 객실 사고 사례를 재구성한 영상을 보다가, 영상이 멈추는 순간 직접 판단해 보는 훈련용 웹앱입니다. 설치나 회원가입 없이 브라우저에서 바로 쓸 수 있습니다.

  • 대상: 객실승무원 교육생, 항공서비스 전공 학생, 이들을 가르치는 교관
  • 방식: 영상 시청 → 자동 정지 → 4지선다 판단 → 해설 → 이어보기 → 학습 정리
  • 현재 수록 사례: 1건
항목내용
사례 번호객실 사고사례 #01
제목착륙 충돌 후 비상탈출
바탕 사고아시아나항공 214편, 2013년 7월 6일, B777-200ER, 샌프란시스코 28L 활주로
영상 길이약 83초 (세로 9:16, 가로 16:9 두 가지)
퀴즈3문항 (이상 징후 감지, 사용 불가 출구, 탈출 개시 판단)
정리 자료핵심 교훈 카드 4장(한영 병기), 비상탈출 구령 연습

영상은 NTSB 공개 조사 결과를 바탕으로 도형으로 그린 교육용 재구성 애니메이션이며, 실제 사고 영상이 아닙니다. 사람 목소리나 비명은 들어 있지 않습니다.

시작하기

교관에게 받은 주소를 휴대폰이나 PC 브라우저로 열면 바로 시작됩니다.

항목권장
기기휴대폰(세로·가로 모두 지원), 태블릿, PC
브라우저최신 Chrome, Safari, Edge, Samsung Internet
소리이어폰 또는 스피커 (효과음과 배경음이 학습에 포함됨)
네트워크영상을 받을 수 있는 연결 (두 영상과 이미지를 합쳐 약 9MB)

앱을 직접 실행하거나 배포하는 방법은 교관·관리자용에 있습니다.

화면별 사용법

앱은 목록, 플레이어, 퀴즈, 학습 정리, 설정 다섯 화면으로 이루어져 있습니다.

1. 목록 (처음 화면)

사고사례 카드가 나열됩니다. 카드에는 포스터, 사례 번호와 제목, 사고 일자·기종·장소, 영상 길이, 퀴즈 문항 수가 표시됩니다. 이미 이수한 사례에는 초록색 이수 완료 표시가 붙습니다.

  • 카드를 누르면 플레이어가 열립니다.
  • 오른쪽 위 설정 버튼으로 설정 창을 엽니다.

3. 퀴즈

영상이 정해진 장면에서 자동으로 멈추고 퀴즈 창이 뜹니다. 퀴즈를 풀기 전에는 영상이 다시 재생되지 않습니다.

  1. 질문을 읽고 ①~④ 중 하나를 누릅니다. 한 번 고르면 바꿀 수 없습니다.
  2. 정답이면 정답입니다, 오답이면 오답입니다 · 정답 ②처럼 결과가 나옵니다. 정답 보기는 초록색, 내가 고른 오답은 빨간색으로 표시됩니다.
  3. 아래에 해설이 나오고, 오답이었다면 ‘왜 그 보기가 틀렸는지’도 함께 보여줍니다.
  4. 이어보기를 누르면 영상이 다시 재생됩니다.

4. 학습 정리

영상이 끝나면 자동으로 열립니다.

  • 점수: ‘3문항 중 n문항 정답’. 모두 맞히면 위에 사고사례 #01 이수 배지가 표시됩니다.
  • 문항별 O/X: 틀리거나 답하지 않은 문항 옆에 장면부터 다시 버튼이 있습니다.
  • 핵심 교훈 카드: ‹ › 버튼으로 4장을 넘겨 봅니다. 한국어와 영어가 함께 적혀 있습니다.
  • 비상탈출 구령 연습: ‘벨트 풀어! 짐 버려! 나와!’를 보여 주고, 구령 듣기를 누르면 브라우저가 소리 내어 읽어 줍니다. 따라 외치며 연습하세요.
  • 처음부터 다시 보기: 답을 모두 지우고 새로 수강합니다.

5. 설정

목록 화면의 설정 버튼으로 엽니다. 바꾼 값은 바로 저장되며, 각 항목은 아래 소리·진동 설정에서 자세히 설명합니다.

학습 흐름과 이수 기준

3문항을 모두 맞히면 사고사례 #01 이수로 기록되고, 틀린 문항은 그 장면부터 다시 보고 같은 퀴즈를 다시 풀어 만회할 수 있습니다.

  • 이수 기준: 3문항 모두 정답. 오답 복습에서 답을 고치면 학습 정리에서 다시 채점되어, 모두 맞으면 그때 이수됩니다.
  • 오답 복습: 학습 정리에서 틀린 문항의 장면부터 다시를 누릅니다. 그 문항 하나만 다시 나오고, 풀고 나면 학습 정리로 버튼으로 돌아갑니다.
  • 이수 후: 목록 카드에 이수 완료가 붙고, 다시 볼 때는 진행 바를 눌러 원하는 장면으로 바로 이동할 수 있습니다.

소리·진동 설정

충돌 장면(약 0:26)에는 큰 충돌음과 진동이 나오므로, 부담이 되는 교육생은 수강 전에 설정을 바꾸도록 안내해 주세요.

설정기본값켜면참고
충돌 장면 진동 효과켜짐충돌 순간 기기가 짧게 두 번 진동진동을 지원하는 기기(주로 안드로이드)에서만 동작. 아이폰과 PC는 진동 없음
충돌음 작게꺼짐충돌 직전부터 약 5초 동안 소리를 20%로 줄임아이폰·아이패드는 음량 조절이 막혀 있어 그 구간만 음소거
퀴즈 효과음켜짐퀴즈가 뜨면 ‘딩’, 정답은 올라가는 두 음, 오답은 내려가는 두 음‘소리 꺼짐’ 상태에서는 울리지 않음

플레이어의 소리 켜짐 / 소리 꺼짐 버튼은 영상 소리와 퀴즈 효과음을 모두 끕니다. 모든 설정은 쓰고 있는 브라우저에 저장되어 다음에 열어도 유지됩니다.

강의실에서 여러 명이 함께 볼 때는 이어폰 사용을 권합니다. 하나의 화면을 프로젝터로 함께 볼 때는 충돌음 작게를 켜 두는 것이 좋습니다.

자주 묻는 질문

영상을 앞으로 넘길 수 없어요

처음 수강할 때는 일부러 막아 두었습니다. 이미 본 구간으로 되감기는 됩니다. 3문항을 모두 맞혀 이수하면 진행 바를 눌러 원하는 장면으로 이동할 수 있습니다.

이수 표시가 사라졌어요

이수 기록은 그 기기의 그 브라우저에만 저장됩니다. 다른 기기나 브라우저, 시크릿(개인정보 보호) 창에서 열거나 방문 기록을 지우면 보이지 않습니다.

교관이 교육생의 점수를 볼 수 있나요?

아니요. 점수와 이수 기록은 서버로 보내지 않습니다. 확인이 필요하면 교육생에게 학습 정리 화면(이수 배지)을 캡처해 제출하도록 안내해 주세요.

다시 처음부터 풀고 싶어요

학습 정리의 처음부터 다시 보기를 누르거나 목록에서 카드를 다시 누르면 답이 초기화됩니다. 이미 받은 이수 기록은 그대로 남습니다.

영상이 재생되지 않아요

index.html을 파일로 직접 열었다면 로컬 서버나 호스팅 주소로 열어 보세요. 네트워크가 느리면 영상을 받는 데 시간이 걸릴 수 있습니다.

진동이 안 와요

아이폰과 PC 브라우저는 웹 진동을 지원하지 않습니다. 안드로이드에서는 설정의 진동 항목과 휴대폰 무음·진동 설정을 확인하세요.

아이폰에서 충돌 장면 소리가 아예 안 나요

‘충돌음 작게’가 켜져 있으면 아이폰은 그 구간만 음소거합니다. 소리를 듣고 싶다면 설정에서 끄세요.

‘구령 듣기’가 아무 소리가 없어요

브라우저 음성 읽기 기능을 쓰므로, 기기에 한국어 음성이 없으면 소리가 나지 않거나 다른 목소리로 읽습니다. 지원하지 않는 브라우저에서는 안내 창이 뜹니다.

실제 사고 영상인가요?

아닙니다. NTSB 공개 자료를 바탕으로 도형으로 그린 교육용 재구성 영상입니다.

사고사례는 js/cases.js 파일 하나에 모여 있어, 코드를 거의 건드리지 않고 문항을 고치거나 사례를 늘릴 수 있습니다.

실행과 배포 파일 구성 문항·해설 고치기 사고사례 추가하기 영상 다시 만들기

실행과 배포

앱은 정적 파일만으로 동작하므로 빌드 과정이 없습니다.

내 컴퓨터에서 실행하기

  1. 저장소 폴더에서 터미널을 열고 아래 명령을 실행합니다.
  2. 브라우저에서 http://localhost:8000 을 엽니다.
python3 -m http.server 8000

index.html을 파일로 바로 더블클릭해 열면 일부 브라우저에서 영상이 재생되지 않을 수 있으니 꼭 로컬 서버로 여세요.

교육생에게 배포하기

GitHub Pages, Netlify, Vercel 같은 정적 호스팅에 저장소 폴더를 그대로 올리면 됩니다. 이 설명서도 함께 배포되어 /guide.html 주소로 열리고, 앱 첫 화면의 설명서 버튼과 연결됩니다.

문항·해설 고치기

js/cases.js에서 해당 문장을 찾아 바꾸고 저장하면 됩니다. 자주 고치는 항목은 아래와 같습니다.

탈출 구령과 승무원의 탈출 개시 권한은 항공사마다 다르므로, 수업에 쓰기 전에 소속 기관 매뉴얼에 맞게 고쳐 주세요.

사고사례 추가하기

  1. 새 영상(세로·가로)과 포스터를 media/ 폴더에 넣습니다.
  2. js/cases.js의 FR_CASES 목록에 #01과 같은 형식의 항목을 하나 더 넣습니다. id는 사례마다 달라야 합니다.
  3. videos.portrait, videos.landscape에 영상 경로를, duration에 영상 길이(초)를, impactAt에 진동·충돌음 조절을 적용할 시점(초)을 적습니다.
  4. 퀴즈는 영상에서 나오는 순서대로 적습니다. 퀴즈 번호가 이 순서를 따릅니다.
  5. 저장한 뒤 앱을 새로 고침하면 목록에 새 카드가 나타납니다.

영상 다시 만들기

영상의 문구나 수치를 바꾸려면 tools/render.py를 고친 뒤 다시 만듭니다. Python 3, Pillow, NumPy, ffmpeg, Noto Sans CJK 한글 폰트가 필요합니다.

cd tools
python3 render.py ../media/oz214_9x16.mp4
python3 render169.py ../media/oz214_16x9.mp4

음향은 외부 음원 없이 tools/soundtrack.py로 합성하며, 만든 뒤 ffmpeg로 영상에 입힙니다.

python3 soundtrack.py soundtrack.wav
ffmpeg -i ../media/oz214_9x16.mp4 -i soundtrack.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 128k -shortest -movflags +faststart out.mp4

장면 길이를 바꾸면 js/cases.js의 pauseAt, reviewFrom, impactAt도 함께 맞춰야 퀴즈가 제 장면에서 멈춥니다.
