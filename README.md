# Flight Ready · 객실 사고사례 훈련

객실승무원 교육생과 항공서비스 전공 학생이 실제 사고 사례 영상을 보다가, 영상이 멈추는 지점에서 직접 판단해 보는 훈련용 웹앱입니다. 영상 퀴즈 훈련, 비상탈출 지휘 시뮬레이션, 학생 질문에 답하는 AI 교관 챗봇(Claude)이 들어 있습니다. 챗봇을 뺀 기능은 설치·빌드 없이 정적 파일만으로 동작합니다.

## 실행

```bash
python3 -m http.server 8000
```

(정적 서버에서는 영상·퀴즈·시뮬레이션이 모두 동작하고, AI 교관 챗봇만 서버 함수가 없어 연결되지 않습니다. 챗봇은 아래 'API 키 설정' 참고.)

브라우저에서 http://localhost:8000 을 엽니다. `index.html`을 파일로 바로 열면 일부 브라우저에서 영상이 막힐 수 있으니 로컬 서버로 여세요. GitHub Pages나 Netlify 같은 정적 호스팅에 그대로 올려도 됩니다.

## 비상탈출 시뮬레이션

첫 화면 **직접 지휘해 보기**에서 시작합니다. 학생이 객실 책임 승무원이 되어 객실 평면도(승객 140명, 출구 8개) 위에서 직접 판단합니다.

| 단계 | 내용 |
|---|---|
| ① 착륙 전 점검 | 15초 안에 벨트 미착용 승객 6명 찾기. 못 찾은 승객은 충격 때 다침 |
| ② 충격 대비 | 6초 안에 행동 선택 (정답: 본인 Brace + "머리 숙여! 자세 낮춰!") |
| ③ 상황 판단 | 출구별 창밖 확인 → 조종실 보고 → 탈출 개시. 아무 판단이 없으면 90초 뒤 조종실이 지시 |
| ④ 탈출 지휘 | 출구 개방·차단·재유도, 탈출 구령, "짐 버려!". 열어야 드러나는 고장(슬라이드 기내 팽창, 문 변형) 있음. 화재가 있으면 시간이 갈수록 객실 연기 증가 |
| ⑤ 결과 | 점수, 정지 후·탈출 개시 후 탈출 시간, 부상자와 원인, 판단별 O·△·X 평가, AI 교관 해설 |

시나리오 3종(우측 후방 화재·슬라이드 이상 / 좌측 날개 화재·문 변형 / 활주로 이탈·후방 동체 손상)과 무작위 모드가 있습니다. 시나리오는 `js/sim.js` 맨 위 `SCENARIOS`에서 출구별 위험(`fire`, `debris`, `slideIn`, `jammed`)을 바꿔 늘릴 수 있습니다. 승객 속도·출구 처리량은 교육용으로 단순화한 값입니다.

## AI 교관 챗봇

모든 화면 오른쪽 아래 **🤖 AI 교관** 버튼. 지금 보는 화면(영상·퀴즈·시뮬레이션 결과)과 사고사례 자료를 함께 보내 맥락에 맞게 답합니다. 퀴즈를 푸는 중에는 정답 대신 힌트부터 줍니다.

- **모델 선택**: 설정에서 Claude 모델을 고릅니다. 기본은 Claude Opus 5.5.
- **↻ 최신 모델 불러오기**: Models API로 그 키에서 쓸 수 있는 모델을 최신순으로 받아 오고 계열별 최신 모델에 '최신' 표시. 키가 있으면 하루 한 번 자동 갱신.
- **답변 깊이**: low(기본) / medium / high (`effort`, 지원하는 모델에만 전송).
- Opus 5.5·Sonnet 5.5 등은 서버측 거절 대체(`fallbacks: "default"`)를 켜 두었습니다.

### API 키 설정

챗봇은 Vercel 서버 함수(`api/`)를 거쳐 Claude API를 부릅니다. 둘 중 하나를 쓰면 되고, 둘 다 있으면 브라우저의 개인 키가 우선입니다.

1. **서버 키 (수업용 권장)** — Vercel 프로젝트 Settings → Environment Variables에 `ANTHROPIC_API_KEY` 추가 후 Redeploy. 학생은 키 없이 사용.
2. **개인 키** — 챗봇 설정의 'Anthropic API 키' 칸에 입력. 그 브라우저(localStorage)에만 저장되고 질문할 때 이 사이트의 서버 함수로만 전달됩니다.

| 환경변수 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 서버 키를 쓸 때 | 서버에서만 쓰는 API 키 |
| `CHAT_ACCESS_CODE` | 아니요 | 설정하면 이 코드를 입력한 사람만 서버 키로 질문 가능 |
| `CHAT_DEFAULT_MODEL` | 아니요 | 기본 모델 ID (예: `claude-sonnet-5-5`) |

챗봇까지 내 컴퓨터에서 시험하려면 정적 서버 대신 Vercel CLI로 실행합니다.

```bash
npm install
npx vercel dev
```

## 사고사례 #01 · 착륙 충돌 후 비상탈출 (아시아나항공 214편)

화면 기획서 「객실 사고사례 훈련 앱 화면 기획서 #01」을 바탕으로 만들었습니다.

| 기능 | 동작 |
|---|---|
| 영상 | 세로 화면이면 9:16, 가로 화면이면 16:9 영상을 재생. 재생 중 화면을 돌려도 같은 지점부터 이어서 재생 |
| 퀴즈 | 영상이 3번 자동으로 멈추고 4지선다 퀴즈 표시. 고르면 바로 정답·해설·오답 피드백을 보여준 뒤 이어보기 |
| 건너뛰기 | 처음 볼 때는 앞으로 건너뛸 수 없음. 이수한 뒤에는 진행 바를 눌러 이동 가능 |
| 음향 | 장면에 맞춘 효과음과 배경음이 영상에 들어 있음. 재생 화면의 '소리 켜짐/꺼짐' 버튼으로 음소거 |
| 충돌 진동·충돌음 | 충돌 장면에서 진동(지원 기기만). 설정에서 진동을 끄거나 충돌음을 작게 할 수 있음(아이폰은 그 구간만 음소거) |
| 퀴즈 효과음 | 퀴즈가 뜰 때, 정답·오답일 때 짧은 알림음. 설정에서 끌 수 있음 |
| 학습 정리 | 점수와 문항별 O/X, 핵심 교훈 카드 4장(한영 병기), 비상탈출 구령 듣기(브라우저 음성 읽기) |
| 오답 복습 | 틀린 문항을 누르면 해당 장면부터 다시 재생한 뒤 같은 퀴즈를 다시 풂 |
| 이수 | 3문항 모두 맞히면 '사고사례 #01 이수' 배지. 이수 기록은 그 브라우저에만 저장됨 |

퀴즈 정지 시점은 영상 장면 순서를 따릅니다.

| 순서 | 정지 시점 | 주제 | 오답 복습 시작 지점 |
|---|---|---|---|
| 퀴즈 1 | 0:25.3 | 이상 징후 감지 | 0:11.5 |
| 퀴즈 2 | 0:42.9 | 사용 불가 출구 | 0:33.5 |
| 퀴즈 3 | 0:57.4 | 탈출 개시 판단 | 0:48.0 |

## 파일 구성

```
index.html        화면 (목록 · 플레이어 · 퀴즈 · 학습 정리 · 설정)
guide.html        사용 설명서 (교육생용 · 교관·관리자용 탭). 앱 첫 화면의 '설명서' 버튼과 연결
css/app.css       스타일
css/guide.css     설명서 스타일
js/cases.js       사고사례 데이터 (영상 경로, 퀴즈 문항·해설, 정지 시점, 교훈)
js/app.js         동작 (재생, 자동 정지, 채점, 복습, 저장)
js/sim.js         비상탈출 시뮬레이션 (시나리오, 승객 이동, 평가)
js/chat.js        AI 교관 챗봇 화면 (모델 선택·최신 모델 불러오기, 키 설정, 대화)
api/chat.js       Vercel 서버 함수: 질문을 Claude로 전달하고 답을 스트리밍
api/models.js     Vercel 서버 함수: 최신 모델 목록
api/config.js     Vercel 서버 함수: 서버 키·접근 코드 설정 여부
package.json      서버 함수용 Anthropic SDK
media/            영상(세로·가로)과 포스터 이미지
tools/            영상을 다시 만드는 스크립트 (render.py 세로, render169.py 가로, soundtrack.py 음향)
```

## 사고사례 추가하기

`js/cases.js`의 `FR_CASES` 배열에 같은 형식의 항목을 하나 더 넣으면 목록에 나타납니다. 영상은 `media/`에 두고 `videos.portrait`, `videos.landscape`에 경로를 적습니다. 퀴즈의 `pauseAt`은 영상이 멈출 시점(초)이고, `reviewFrom`은 오답 복습을 시작할 시점(초)입니다.

## 영상 다시 만들기

영상은 공개 조사 결과를 바탕으로 도형으로 그린 교육용 재구성 애니메이션이며, 실제 사고 영상이 아닙니다. 문구나 수치를 바꾸려면 `tools/render.py`를 고친 뒤 다시 만듭니다. Python 3, Pillow, NumPy, ffmpeg, Noto Sans CJK 한글 폰트가 필요합니다.

```bash
cd tools
python3 render.py ../media/oz214_9x16.mp4
python3 render169.py ../media/oz214_16x9.mp4
```

음향은 외부 음원 없이 `tools/soundtrack.py`로 직접 합성합니다. 장면별 구성은 파일 맨 위 주석에 있습니다. 비명이나 사람 목소리는 넣지 않았습니다. 영상을 다시 만든 뒤 음향을 입히려면:

```bash
python3 soundtrack.py soundtrack.wav
ffmpeg -i ../media/oz214_9x16.mp4 -i soundtrack.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 128k -shortest -movflags +faststart out.mp4
```

장면 길이를 바꾸면 `js/cases.js`의 `pauseAt`, `reviewFrom`, `impactAt`도 함께 맞춰야 합니다.
